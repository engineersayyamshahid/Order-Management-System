## 🎯 01 — The Problem I Am Solving

Small businesses often manage customer orders through WhatsApp messages, spreadsheets, manual payment records, and separate dispatch lists.

This fragmented workflow creates several problems:

- **Lost Order Information:** Customer details and order requirements may be scattered across different messages.
- **Payment Confusion:** Received amounts and outstanding balances can be difficult to track.
- **Approval Delays:** Administrators may struggle to identify and review pending orders.
- **Limited Transparency:** Employees need a simple way to check order progress and commission summaries.
- **Dispatch Difficulties:** Tracking numbers and parcel information may not be maintained in one place.
- **Manual Reporting:** Preparing order and payment summaries takes extra time and effort.

### 💡 My Solution

OrderFlow brings these workflows together in one role-oriented web interface.

Employees can submit and monitor orders, while administrators can review approvals, inspect payment information, manage employees' order records, and organize dispatch information.

The system combines a modern dashboard experience with interactive animations and a distinctive visual identity.

**The goal is to make order management more organized, accessible, and efficient.**

## 🎨 02 — Midnight Teal Design System

OrderFlow uses a custom visual theme called **Midnight Teal**.

The theme combines deep navy backgrounds, teal interface elements, turquoise highlights, coral notifications, and warm gold accents.

It creates a premium SaaS dashboard appearance while maintaining readability and visual consistency.

### 🌈 Official UI Color Palette

| Color | Hex Code | Purpose |
|---|---|---|
| Midnight Navy | `#102B3A` | Main dark backgrounds, sidebar, and navigation |
| Deep Teal | `#087F8C` | Primary buttons and active navigation |
| Bright Turquoise | `#12B8A6` | Highlights, success states, and interactive elements |
| Soft Coral | `#F28C68` | Notifications, warnings, and attention indicators |
| Warm Gold | `#EFBD62` | Financial information, commissions, and premium highlights |
| Soft White | `#F4F7F8` | Light-mode backgrounds and content surfaces |

### 🎯 How the Colors Are Used

- **Midnight Navy:** Creates a professional foundation for the application.
- **Deep Teal:** Identifies important actions and navigation elements.
- **Bright Turquoise:** Highlights active states and successful operations.
- **Soft Coral:** Draws attention to important notifications and warnings.
- **Warm Gold:** Gives payment and commission information a distinct appearance.
- **Soft White:** Provides a clean and comfortable light-mode experience.

### 🌓 Dark & Light Mode

OrderFlow supports two visual modes:

**Dark Mode**
- Deep navy backgrounds.
- Teal and turquoise interactive elements.
- High-contrast text and dashboard cards.
- A modern, premium interface.

**Light Mode**
- Soft white and light backgrounds.
- Clear typography and readable content.
- Teal primary buttons and highlights.
- Comfortable dashboard navigation.

The theme preference can be saved in browser localStorage so the selected appearance remains available after refreshing the page.

## 🔐 08 — Security and Limitations

OrderFlow is an academic frontend prototype, not a production-ready order management platform.

Important limitations:

- Demo login is not real server-side authentication.
- Browser localStorage is not a secure database.
- Demo records are stored locally in the browser.
- Receipt selection does not guarantee secure server-side file storage.
- Payment information is not verified against a payment provider.
- Backend authorization and role enforcement are not implemented.
- Demo data should not be treated as real business records.

**Never enter real customer information, passwords, payment details, or other sensitive data into the demonstration application.**

### Future Production Security

A production version would require:

- Secure authentication and session management.
- Server-side role-based access control.
- Database integration.
- Input validation and secure APIs.
- Secure file uploads and storage.
- Payment verification.
- Audit logs and activity tracking.
- Automated testing and backups.
- Secure deployment and HTTPS.

# OrderFlow — Animated Order Management System

A responsive, animated vanilla HTML/CSS/JavaScript demo inspired by the supplied OrderFlow prototype.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code Live Server.
3. Sign in with either role. Demo password: any non-empty value.

## Demo accounts
- Employee: `employee@orderflow.demo`
- Admin: `admin@orderflow.demo`

## Features
- Animated illustrated login scene (traveller with suitcase, second character opening a glowing case)
- Employee and admin workspaces
- Create, view, search and filter orders
- Approve/reject orders
- Demo commission calculation (5% of approved order values)
- Dispatch status and tracking-code generation
- CSV export and print
- Persistent browser demo data using `localStorage`
- Dark/light theme toggle (preference saved in browser)
- Responsive navigation, toast notifications and reduced-motion support

## Important
This is a front-end prototype. It has no real authentication, server, database, payment verification, file upload storage, or access control. Do not use real customer information. For production, add a secure backend, database, server-side authorization, validation, audit logs and payment-provider integration.
